# Predicting-Loan-Default
Predicting Loan Default using a XGBoost model based on borrower financial features with a 71% recall score 
- Data preprocessing and data wrangling
- Feature selection using Random Forest
- XGBoost model fitting using parameters tuned via K-Fold cross validation
- Interpreted model predictions using SHAP values to identify the most influential borrower financial features driving default risk

# Data
The full data for this project cannot be publicly posted due to privacy reasons. The variables available in the data is written down in data_desc.ipynb
